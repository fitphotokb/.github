# FitPhotoKB — Free Image Compressor to Any KB or MB Size

[FitPhotoKB](https://fitphotokb.com/) is a free, browser-based image 
compression tool that lets you compress any image to an exact file size 
target — no uploads, no account, no installation required.

## What it does

- Compress JPEG, PNG, WebP, AVIF, and HEIC images to any KB or MB target
- Automatically finds the highest quality that fits under your limit
- Batch compress up to 20 images at once
- Resize image dimensions when needed to reach aggressive targets
- Convert between formats — HEIC to JPEG, WebP to JPEG, PNG to WebP, and more
- Preserve transparency in WebP, AVIF, and PNG output
- 100% local processing — your images never leave your device

## Browser Extension

FitPhotoKB is also available as a free browser extension for Chrome, 
Microsoft Edge, and Firefox. Right-click any image on the web to compress 
it instantly — no need to save it first.
